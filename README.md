# 🌌 AuraTravel Maharashtra AI

AuraTravel Maharashtra AI is a futuristic travel website built using HTML, CSS, and JavaScript.
The platform helps users explore beautiful destinations in Maharashtra with an AI-inspired interface and interactive travel experience.

---

## ✨ Features

* 🌍 Modern AI-based travel UI
* 🏖️ Maharashtra destination explorer
* 🚩 Category filters (Beaches, Forts, Hill Stations)
* 🤖 AI-inspired search experience
* 💎 Glassmorphism & Neon UI Design
* 📱 Fully Responsive Layout
* 🧠 Interactive destination cards
* 🛎️ Booking modal popup
* ⚡ Smooth animations and transitions

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts
